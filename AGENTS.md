# ASM Tool 0.12.3 — правила разработки

Текущая версия исходников в основной ветке — **0.12.3**. Официальное пользовательское описание: [README.md](README.md), актуальные инженерные сведения: [docs/patch123/](docs/patch123/).

## Границы проекта

- Go CLI: `cmd/`, `internal/`, `assets/`.
- Windows GUI: `ui/windows/` (C#, WinUI 3, .NET 10).
- Linux: Go CLI с терминальным интерактивным режимом; не приписывать ему неподтверждённую отдельную TUI-реализацию.
- Сборка/комплектация: `packaging/`, `tools/`.
- Лицензирование сторонних компонентов: `licenses/patch123/`, `docs/patch123/`.
- Фикстуры действующих Go-тестов: `testdata/`.

В GitHub не публикуются внутренние `planning/` журналы, пользовательские запросы и сырые сборочные логи. Локальные рабочие копии остаются независимыми от текущей ветки.

Исторические Python-деревья `reference/`, миграционная `inventory/`, старые генераторы и журналы фаз не являются частью этого GitHub-дерева. Не восстанавливать их без явного решения. Исторические упоминания в сохранённых отчётах и regression fixtures не являются зависимостями runtime.

## Безопасность и совместимость

Исследовать только цели с подтверждённой авторизацией. Сохранять scope, подтверждение активных профилей, ограничение запросов, корректную неполноту результата и provenance. Запрещено превращать повреждённый `run_status.json` или ошибки worker в успешный статус.

Nmap из 0.12.3 исключён; никаких флагов `--service-detection` ради обратной совместимости. Нативный Go TCP-порт-сканер и `--ports` — отдельный контракт. Не добавлять Python, AI/Ollama и скрытые сетевые fallback. Windows GUI запускает Go EXE отдельно и использует аргументы без shell; сохранять Job Object и подтверждение принудительного завершения.

Браузерная подсистема — `NOT_SECURITY_QUALIFIED`; исторический candidate31 — `FAIL`. Нельзя представлять её сетевую изоляцию проверенной. Не выдавать исторические Windows GUI-тесты за проверки нового релизного архива.

## Лицензирование и публикация

Собственный код выпущен владельцем под MIT; правообладатель указан в `LICENSE` и `licenses/patch123/PROJECT_LICENSE_METADATA.json`. Публичная готовность — `NOT_CONFIRMED`. Открыты Microsoft CRT redistribution, Rust/V8 binary closure и LGPL sufficiency, полная юридическая проверка notices и нативная квалификация GUI. Происхождение Linux Obscura worker подтверждено сравнением с upstream release; Windows GUI статически собран и проинвентаризирован. Это не равно общей runtime/security-квалификации. Соответствующие исходники glibc/GCC и notices не удалять ради уменьшения размера репозитория без равноценного доступного комплекта.

GitHub `main` — текущие исходники. Никакая подготовка или аудит не является разрешением менять исследовательскую логику, запускать сканирования, делать публичный выпуск, менять visibility или перезаписывать бинарные Release Assets.

## Квалификация

Разделять: `BUILD/INTEGRITY PASS`, `NATIVE NOT_RUN`, `SECURITY NOT_QUALIFIED`, `PUBLIC_REDISTRIBUTION NOT_CONFIRMED`. Итоговая информация о ZIP и версиях — [RELEASE_ARTIFACT_VERIFICATION.md](docs/patch123/RELEASE_ARTIFACT_VERIFICATION.md). При изменениях выполняйте только релевантные проверки, не заявляя общий PASS на основании узкого теста.
