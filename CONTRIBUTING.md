# Вклад в ASM Tool

Сохраняйте требования к авторизации исследований, проверке целевой области, ресурсным лимитам, регистрации ошибок и неполных результатов. Не запускайте активные сетевые проверки без разрешения владельца цели.

Исходники Go: `cmd/` и `internal/`; GUI: `ui/windows/`. При изменении поведения добавляйте тесты. Проверку Go можно начать командой:

```sh
go test -short ./internal/... ./cmd/... ./tools/portablepayload
```

Некоторые сценарии могут требовать дополнительных фикстур или конкретной ОС; фиксируйте отрицательные результаты, не заменяя их заявлением `PASS`. Windows GUI нуждается в нативной проверке на Windows.

При добавлении сторонних компонентов сохраняйте обязательные лицензии, notices и исходники. Не коммитьте логины, токены, локальные архивы, логи исследований, бинарные дистрибутивы и внутренние отчёты.
