# Политика безопасности ASM Tool

## Статус 0.12.3

ASM Tool предназначен для исследований **только с разрешения владельца цели**. Наличие профилей `verify` и `full` не означает разрешения на исследование произвольных систем.

Браузерная изоляция/Obscura **NOT_SECURITY_QUALIFIED**; зафиксирован исторический candidate31 **FAIL**. Актуальный portable-комплект не проходил полной повторной проверки Windows native/browser security после исправления версии. Принудительная остановка Windows GUI может приводить к неполному результату.

## Сообщение об уязвимости

Не публикуйте в открытых Issue токены, приватные данные, доказательства эксплуатации с чувствительными сведениями или сведения о чужих системах. Используйте приватный канал владельца репозитория на GitHub или механизм приватных Security Advisories, **если он включён**. Контактные адреса для security-reporting должны быть явно утверждены владельцем; этот документ не выдумывает адрес.

При сообщении желательно указать версию/платформу, воспроизводимые минимальные шаги без несанкционированной сетевой активности, ожидаемый и фактический результат, возможное влияние и данные диагностики после удаления секретов.

## Обязательства

Ни успешная сборка, ни HASH/CRC ZIP, ни исторический PASS тестов не заменяют актуальный аудит безопасности. Не обходить встроенные ограничения области исследования, сетевой изоляции, количества запросов и авторизации ради воспроизведения дефекта.
