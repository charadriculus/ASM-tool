# Безопасность ASM Tool

ASM Tool используется только при наличии разрешения на исследование. Активные режимы требуют подтверждения полномочий и ограничены заданной областью проверки.

Успешная компиляция и совпадение SHA-256 не эквивалентны проверке сетевой изоляции, GUI и браузерной подсистемы. Для заявлений о безопасности необходимы отдельные испытания.

Для сообщения об уязвимостях используйте приватный канал GitHub Security Advisories, если он включён. Не публикуйте в открытых Issues секреты, чужие персональные данные и сведения для эксплуатации. Сообщение должно содержать версию, ожидаемое и фактическое поведение, воспроизводимые шаги без несанкционированной активности.
