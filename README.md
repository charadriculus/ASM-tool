# ASM Tool 0.12.3

ASM Tool — инструмент для сбора, проверки и структурирования
информации о разрешённых объектах исследования.

Основное ядро реализовано на Go.

## Поддерживаемые платформы

- Linux x86-64: CLI и интерактивный терминальный режим.
- Windows x64: CLI и графический интерфейс GUI.

Windows GUI реализован на C#, WinUI 3 и .NET 10.

Готовые portable-комплекты не требуют установки Go SDK,
Python или .NET SDK.

Некоторые системные компоненты Windows могут потребовать
наличия соответствующей среды выполнения.

## Возможности

- Пассивный сбор информации.
- Проверка DNS и сетевых сервисов.
- Профили Passive, Verify и Full.
- Браузерные проверки с использованием Obscura.
- Интеграция Subfaster.
- Формирование отчётов JSON, HTML и PDF.
- Поддержка русского и английского языков отчётов.
- Мониторинг выполнения и состояния исследования.
- Проверка целостности portable-комплекта.

Nmap не входит в состав ASM Tool 0.12.3.

Доступность отдельных функций зависит от профиля,
конфигурации и действующих ограничений безопасности.

## Установка

Откройте черновик выпуска 0.12.3 в разделе GitHub Releases
для пользователей с доступом к приватному репозиторию.

Подготовлены следующие архивы:

- ASM_Tool_0.12.3-linux-x86_64.zip
- ASM_Tool_0.12.3-windows-x64.zip
- ASM_Tool_0.12.3-Linux-Windows.zip

Скачайте архив для своей платформы.

Распакуйте его полностью, сохраняя структуру каталогов,
включая payload и файлы контрольных сумм.

Проверьте целостность файлов по SHA256SUMS.

## Windows

Графический интерфейс запускается через:

    ASMTool.exe

Консольный инструмент:

    asm-tool.exe

Для получения справки:

    asm-tool.exe --help

## Linux

Для получения справки:

    ./asm-tool --help

Доступные режимы и параметры определяются установленной
версией исполняемого файла.

## Авторизация исследований

ASM Tool предназначен для исследований объектов, на
проверку которых пользователь имеет соответствующее разрешение.

Активные режимы требуют явного подтверждения авторизации.

Наличие GUI не отменяет ограничений безопасности Go-ядра.

## Разработка

Исходный код Go находится в каталогах cmd и internal.

Конфигурация portable-комплектов и инструменты их создания
находятся в packaging и tools.

Исходники Windows GUI, его проекты C# и необходимые
сборочные материалы включены в репозиторий.

Для сборки Go-ядра используется версия Go,
соответствующая требованиям go.mod.
