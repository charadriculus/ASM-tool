# ASM Tool

ASM Tool 0.12.3 — инструмент для сбора, проверки и представления информации об объектах исследования с разрешения владельца.

Основное приложение написано на Go. Поддерживаются Linux x86-64 (CLI и интерактивный режим) и Windows x64 (CLI, а также GUI на C# / WinUI 3 / .NET 10).

## Возможности

Пассивный сбор данных, DNS/HTTP/TCP-проверки в пределах разрешённой области исследования; профили passive, verify и full; браузерные проверки посредством Obscura; интеграция Subfaster и Typst; отчёты JSON, HTML и PDF.

Активные проверки требуют явного подтверждения полномочий на исследование. Наличие исходников не означает разрешения на проверку сторонних ресурсов.

## Сборка

Исходники Go: `cmd/`, `internal/`, `assets/`. GUI Windows: `ui/windows/ASMTool.Gui/`. Команды компиляции и её ограничения: [docs/BUILDING.md](docs/BUILDING.md).
