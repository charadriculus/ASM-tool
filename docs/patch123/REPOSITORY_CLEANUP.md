# GitHub main — очистка ASM Tool 0.12.3

## Подтверждённое содержимое

В основной ветке сохранены исходники Go, Windows GUI, действующие регрессионные фикстуры, portable-инструменты, документация текущего патча и необходимый лицензионный корпус. Runtime- и GUI-бинарники **не пересобирались** в рамках очистки GitHub; все три Release ZIP и их SHA-256 сохранены.

Из актуального Git-дерева удалены:
- `reference/` (Python 0.11.3 и старые снимки);
- `inventory/` (миграционная инвентаризация);
- `scripts/` (устаревшие генераторы Python-фикстур);
- `planning/` (исторические фазы, исходные запросы, внутренние ревью и сырые логи);
- устаревшие инструкции Codex, архивные документы старых патчей и тестовые материалы, не требующиеся текущему Go-ядру.

`testdata/` сохранён: историческое имя отдельной фикстуры не означает наличие Python/Nmap в runtime и не является основанием для удаления работающих регрессионных входных данных.

## Лицензии

`licenses/patch123/` сохраняет notices, provenance и corresponding-source материалы GNU glibc/GCC (включая крупные source archives). Их нельзя удалять ради уменьшения репозитория без доказанного эквивалентного способа выполнения обязательств. `LICENSE` ещё содержит непроверенный copyright holder; `PUBLIC_REDISTRIBUTION_READY = NOT_CONFIRMED`. Вопросы лицензирования будут проверены отдельно.

## Границы очистки и публикации

Удаление из текущего дерева не стирает прежние Git-коммиты, старые теги, черновики Releases и недоступные через обычный API серверные объекты. История требует отдельного этапа удаления/перепривязки устаревших refs и проверки, что новые refs не указывают на legacy.

Специализированный полный аудит секретов всех Git-объектов **не выполнялся**. Приватность репозитория сохранена. Предварительные проверки ZIP и GitHub не являются допуском к публичному распространению.
