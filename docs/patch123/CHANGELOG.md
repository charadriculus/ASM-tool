# ASM Tool 0.12.3 — итоговые изменения

**Состояние: 22 октября 2026 года; версия 0.12.3 без изменения исследовательской логики Go.**

- Интегрирован Windows GUI (C#, WinUI 3, .NET 10) с Go CLI; в итоговом Windows ZIP присутствует `ASMTool.exe`.
- Сохранён Linux Go CLI с существующим терминальным интерактивным режимом; отдельная новая TUI не заявляется.
- Удалён устаревший GUI control `service-detection` и зависимости от Nmap; `--ports` сохранён для нативного Go TCP.
- Обработка `run_status.json` и worker errors делает неопределённый и неполный результат явным; статус `incomplete` не трактуется как success.
- Сохранены безопасная передача ArgumentList, авторизация активных проверок, Windows Job Object и подтверждение принудительного прерывания.
- Сохранены Subfaster, Obscura и Typst; обновлены записи лицензий/уведомлений без автоматического признания публичных прав на распространение.
- Исправлен единый источник версии `internal/version` и HTTP User-Agent (исходный проверенный коммит `47a73ed`).
- Собраны и проверены архивы Linux, Windows CLI+GUI и объединённый Linux+Windows; их SHA-256 — в [README_RU.md](README_RU.md).

## Границы результатов

После последнего исправления проведены целевые Go-тесты (7+12), vet, Linux/Windows build и проверки целостности ZIP. Полная функциональная регрессия и Windows native не повторялись; не заявлять их как PASS. Browser остаётся `NOT_SECURITY_QUALIFIED`, candidate31 `FAIL`; сохраняются нерешённые ограничения безопасности и лицензирования.

Документы, созданные до финальной Windows GUI-сборки, относятся к промежуточным состояниям и могут говорить о `GUI BUILD BLOCKED`. Для итогового комплекта используйте [RELEASE_ARTIFACT_VERIFICATION.md](RELEASE_ARTIFACT_VERIFICATION.md) и этот changelog.
