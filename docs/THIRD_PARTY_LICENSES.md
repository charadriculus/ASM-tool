# Сторонние компоненты: лицензии и уведомления

Собственный исходный код ASM Tool распространяется по [MIT](../LICENSE). Сторонние зависимости сохраняют собственные лицензии.

Исходные тексты лицензий, notices, сопровождающие исходники и метаданные находятся в:

- [Go, Subfaster, GNU runtime](../licenses/patch123/go-runtime/) — реестр [CORPUS.SHA256SUMS](../licenses/patch123/go-runtime/CORPUS.SHA256SUMS).
- [Microsoft .NET, WinUI, Windows App SDK и WebView2](../licenses/patch123/microsoft/) — реестр [PACKAGE_INVENTORY.json](../licenses/patch123/microsoft/PACKAGE_INVENTORY.json).
- [Rust, Obscura, V8, Typst](../licenses/patch123/rust/) — реестр [licenses-index.json](../licenses/patch123/rust/licenses-index.json).

Ранее подтверждено наличие 185 Go/GNU, 37 Microsoft и 101 Rust файлов (323/323 в исходном корпусе). Оригинальные GNU corresponding-source материалы, оригинальные NOTICE и условия отдельных лицензий не удаляются при очистке исходников.

Для любого конкретного бинарного дистрибутива требуется сверка реально входящих компонентов с соответствующими notices, исходными материалами и условиями лицензий. В публичную документацию не включаются внутренние отчёты о ходе аудита.
