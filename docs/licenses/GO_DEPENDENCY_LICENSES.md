# Go runtime and Subfaster dependency notices

Scope: exact Subfaster payloads and their Go module notices for ASM Tool 0.12.3 development. This is a source/provenance record, not a public-release or complete legal qualification.

The Linux Subfaster payload is SHA-256 `bbbe5e8c4adeb71d94e209bf5c9e269b90dbbe2ac63ff7497bac4c4fc830bd30`; the Windows x64 payload is `14f1d2beeb07f5660759bec1fb1f82ca6ff0e342165c1c86870fa52a1a341ba2`. Static Go build metadata identifies Subfaster v2.18.0, built by Go 1.26.6 on Linux and Go 1.26.5 on Windows. No Subfaster binary was executed. The verified Go 1.26.6 SDK hash was `29e6e0b8be61beb1489ceae62b304343566de8a1dc700af74bde7aeb9c80ad45`.

The Linux binary has 108 direct Go module entries and the Windows binary has 107. The common set is 105 modules; Linux adds `github.com/tklauser/go-sysconf v0.3.16`, `github.com/tklauser/numcpus v0.11.0`, and `github.com/zcalusic/sysinfo v1.0.2`; Windows adds `github.com/go-ole/go-ole v1.2.6` and `github.com/yusufpapurcu/wmi v1.2.4`. H1 was recomputed from each exact local module ZIP for all 105 shared modules and matched binary build metadata and the recorded ZIP SHA-256. The three Linux-only module ZIPs were H1-checked against Linux build metadata. The two Windows-only ZIPs were obtained from the official Go module proxy and H1-checked against the Windows build metadata; their exact MIT LICENSE files are included.

The common 151 notice files were copied from the verified Windows payload artifact (archive SHA-256 `a9d81de8ac5433fdcd9dfc0fe646d7dccb29746d09a630f79f1ae6f4ffc2ee4e`). Each file matched both the artifact's `SHA256SUMS` and the reviewed notice lock (`018d566aa20cc38491a1b5a472ede0fc2b585055ea512e8b355eaa033d9fc1f8`). The corpus also includes the three Linux-only module notices, two Windows-only notices, and Subfaster v2.18.0's MIT `LICENSE.md`. Exact origin member, version, SHA-256 and a conservative SPDX field are recorded per file in [`SUBFASTER_PROVENANCE.json`](../../licenses/patch123/go-runtime/SUBFASTER_PROVENANCE.json).

`NOASSERTION` is used for individual copyright-only source files, notices, or signatures that do not themselves state a license. It does not override the module's accompanying license file. Six individual notice entries remain `NOASSERTION`; the manifest also records recognized SPDX expressions from the license texts. These text classifications support attribution review and do not claim a legal opinion. The Windows executable's `go version -m` output has a blank main-module H1 field; the module version/path match v2.18.0, but the Windows binary-to-source identity is not proven by an embedded H1. Linux embeds the H1 for the same module archive.

The Windows-only module archive SHA-256 values are `95b192df81ca16f0fb7d2d98ff6596d70256d73e49e899c55fabd511fd6768ef` (go-ole) and `c2a0a12203162ef8fd6f65e191aac359823d370e113122cbd8e80711ddc9c1f9` (wmi). No dependencies were installed. The full file-level provenance list is in the JSON manifest; this document deliberately does not infer a single license for an entire Cargo/npm or other dependency ecosystem.

The verified Go SDK's BSD-3-Clause license notice is retained under `licenses/patch123/go-runtime/toolchain/`. It applies to the build toolchain, not as a runtime dependency.
