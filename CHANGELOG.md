# Изменения ASM Tool

## 0.12.3 — 22 октября 2026

- Интегрирован Windows GUI на WinUI 3/.NET 10 и Go CLI; подготовлен полный portable ZIP Windows.
- Сохранён CLI/интерактивный режим Linux; Nmap исключён из runtime.
- Скорректирован CLI/GUI-контракт, обработка прогресса, ошибок worker и неполного результата.
- Версия и HTTP User-Agent переведены на общий источник `internal/version`.
- Добавлены лицензионные материалы для сторонних зависимостей и GNU runtime, документированы нерешённые вопросы.
- Проверена целостность релизных Linux, Windows и объединённого ZIP.
- Очищено GitHub-дерево от старой Python-реализации, промежуточных журналов и миграционных артефактов.

**Статус:** приватный черновик. Публичное распространение не подтверждено; безопасность браузерной изоляции не квалифицирована. Полная повторная функциональная квалификация после исправления версии не проводилась.
